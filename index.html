Host This Tracker on GitHub Pages

Free, public or private hosting with zero build configuration

This app is 100% client-side (HTML/CSS/JS). It works immediately on GitHub Pages without installing Node.js, Vite, or Docker!

Step 1: Create a New GitHub Repository

Go to github.com/new and create a repository named e.g. naac-criterion-6-tracker.

Step 2: Push Current Folder to GitHub

Run these commands inside this folder in PowerShell or Git Bash:

git init
git add .
git commit -m "Initial commit of NAAC Criterion VI Tracker"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/naac-criterion-6-tracker.git
git push -u origin main

Step 3: Enable GitHub Pages in 2 Clicks

  1. In your GitHub repo, click Settings > Pages (on left sidebar).
  2. Under Build and deployment > Branch, select main and folder / (root).
  3. Click Save. In ~1 minute, your live URL will appear: https://YOUR_USERNAME.github.io/naac-criterion-6-tracker/!
